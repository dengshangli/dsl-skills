# crm-email-manual-send

[English](./README.md) | 中文

## 简介

一个通过本地 HTML 文件名与 CRM 线索页中的模板名称精确匹配，手动发送 CRM 模板邮件的 Agent Skill。它只发送一次已获授权的模板，并通过新的跟进记录核验成功。

## 功能

- 根据顶层本地 `.html` 文件名建立稳定台账。
- 保留文件名中的空格、标点、中文、大小写和其他细节。
- 在 CRM 模板选择器中搜索唯一精确匹配。
- 只发送用户明确授权的模板。
- 通过最新跟进记录核验结果，不根据主题或弹窗状态猜测。
- 汇总已发送、不可用、阻塞和未完成项目。

## 适用场景

- 将全部本地邮件模板发送给指定 CRM 线索。
- 只重试失败或待核实项目，避免重复发送已成功模板。
- 查找本地存在但 CRM 中不可用的模板。

## 环境要求

- 移除 `.html` 后与 CRM 模板名称完全一致的本地 HTML 文件。
- 已登录目标 CRM 的 Chrome 会话。
- `chrome:control-chrome` Skill。
- 一个明确且符合允许 URL 前缀的 CRM 目标线索页。
- 用户对发送操作的明确授权。

## 安装

```bash
npx skills add dengshangli/dsl-skills --global --agent universal --skill crm-email-manual-send
```

## 使用示例

- “把这个目录中的全部 HTML 模板发送给这个 CRM 线索，并报告不可用模板。”
- “只重试上次运行中阻塞的项目。”
- “检查 CRM 中有哪些本地模板可用，但不要发送。”

## 重要说明

- 浏览和诊断不代表授权发送。只有用户明确要求发送时，才能点击确认按钮。
- 已核验成功的模板会记入台账，除非用户明确要求重复，否则禁止再次发送。
- 出现“暂无数据”表示模板不可用，必须关闭弹窗且不得发送。
- 出现多个匹配或没有精确匹配时应标记阻塞，禁止猜测。
- 新的跟进记录是发送成功的权威信号。
- 此 Skill 不读取浏览器 Cookie、Local Storage、密码或其他会话存储。
